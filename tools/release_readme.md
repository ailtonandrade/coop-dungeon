# Corrumpted

Co-op de sofá e online num ferro-velho brasileiro que já foi cidade. Aqui ficam **só as versões
prontas para jogar**.

## Baixar

Abra **[Releases → a mais nova](../../releases/latest)** e baixe:

- **Windows:** `Corrumpted-vX.Y.Z-Windows.zip` → extraia a pasta e abra `Corrumpted.exe`
  (se o Windows avisar "aplicativo desconhecido": *Mais informações → Executar assim mesmo*).
- **Linux:** `Corrumpted-vX.Y.Z-Linux.zip` → extraia e rode `./Corrumpted.x86_64`.

## Atualizar

Não precisa baixar de novo: com o jogo aberto, quando sair versão nova aparece
**"Tem versão nova · Atualizar agora"**. Ele baixa, troca os arquivos e abre já atualizado.

## Jogar com amigos

- **Sofá:** até 4 no mesmo PC (teclado e controles).
- **Online:** um abre o mundo (host) e passa o código; os amigos entram com ele. Todos precisam
  estar na mesma versão (o jogo avisa e atualiza).
